# VoidWing

Free hand-made hero mods for Heroes of Newerth, installed through Heroes Forge.
มอดฮีโร่ Heroes of Newerth ที่ทำเอง แจกฟรี ติดตั้งผ่าน Heroes Forge

- Site / หน้าเว็บ: https://khattiya-streamer.github.io/voidwing/
- Downloads / ไฟล์มอด: see [Releases](../../releases) (one release per mod)

## Install / วิธีติดตั้ง
1. Download the `.honmod` file from Releases. Do not unzip it.
2. Heroes Forge → **Custom Mod (.honmod)** → **Add .honmod** → pick the file.
3. Switch the mod on, click **Apply**, start the game from Forge.
